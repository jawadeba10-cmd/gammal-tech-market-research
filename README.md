## Market Research — Healthcare Apps

# Overview

This dataset contains 50 negative user reviews collected and categorised from various healthcare and wellness applications.

# Purpose

The goal is to identify common user pain points across competitor platforms to improve healthcare.gammal.tech ecosystem.

# Key Categories





- Bad UX



- Performance Issues



- Pricing Concerns



- Trust & Data Privacy



- Missing Features



- Service Quality

# Insight

- Most negative reviews are related to:





- Poor user experience



- High pricing/subscriptions



- Technical issues (bugs, crashes)



- Lack of trust or inaccurate data

When considering these insights, the healthcare application will improve client satisfaction.
